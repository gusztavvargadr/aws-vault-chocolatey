# Usage

This document describes how to install and use the [`aws-vault` Chocolatey package](https://chocolatey.org/packages/aws-vault).

## Install

1. Install [Chocolatey](https://chocolatey.org/install), which is the only prerequisite.
2. Install the package:

   ```powershell
   choco install aws-vault
   ```

## Use

Once the package is installed, `aws-vault` is on the path. How to use the tool itself is in the [upstream repository](https://github.com/ByteNess/aws-vault).

## Upgrade

Move the tool to the latest published package version:

```powershell
choco upgrade aws-vault
```

## Remove

Remove the tool and the package:

```powershell
choco uninstall aws-vault
```
