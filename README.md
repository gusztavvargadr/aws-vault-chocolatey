The [Chocolatey package](https://chocolatey.org/packages/aws-vault) of [AWS Vault](https://github.com/ByteNess/aws-vault) by [ByteNess](https://github.com/ByteNess).

## Usage

With [Chocolatey](https://chocolatey.org/install) installed:

```powershell
choco install aws-vault
choco upgrade aws-vault
choco uninstall aws-vault
```

How to use the tool itself is in the [upstream repository](https://github.com/ByteNess/aws-vault).
